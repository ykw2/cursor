HTML · CSS · JavaScript

標記、樣式、行為，各放一層。

這個專案把靜態網站拆成三個找得到的地方。改 index.html 會改內容，改 src/styles 會改外觀，改 src/scripts 會改互動。

HTML

index.html 負責標題、段落、表單與導覽。

CSS

src/styles 負責顏色、字級、版面與元件。

JavaScript

src/scripts 負責主題、選單與記事。

01 — 目錄

檔案各管一件事。

從入口頁往下看，標記、靜態檔、樣式與腳本不會混在同一個檔案裡。

  • index.html 頁面結構與一打開就看得到的內容
  • public/ 原樣提供的靜態檔
    • favicon.svg 瀏覽器分頁圖示
  • src/styles/ 外觀，依職責拆開
    • tokens.css 顏色、字體、間距
    • base.css 重置與內文排版
    • layout.css 頁首、版面、頁尾
    • components.css 目錄、色票、記事卡
  • src/scripts/ 行為，一個模組一件事
    • main.js 入口，把樣式與模組接上頁面
    • theme.js 淺色與深色，並記住選擇
    • nav.js 選單、目前區塊、捲動時的頁首
    • swatches.js 把色票換成目前的顏色值
    • notes.js 記事的新增、刪除與保存
02 — 樣式

顏色集中在變數裡。

三層各自有一個識別色，定義在 tokens.css。換主題時只改變數，元件不用各寫一套。

HTML --html 標記層
CSS --css 樣式層
JavaScript --js 行為層
03 — 腳本

記事留在這台瀏覽器。

表單寫在 HTML，外觀寫在 CSS，儲存與清單由 notes.js 處理。重新整理後，記事還在。
